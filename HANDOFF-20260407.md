## How to Continue

### Required Clerk Keys
Before starting Phase 5, you need these from https://dashboard.clerk.com → Your App → API Keys:
1. **`NEXT_PUBLIC_CLERK_PUBLISHABLE_KEY`** — Frontend Clerk SDK key
2. **`CLERK_SECRET_KEY`** — Backend secret key for token verification

Also configure Google OAuth in Clerk dashboard: User Authentication → Social Connections → Google.

### Setup Steps
1. **Install backend dependencies:** `cd backend && npm install`
2. **Install Clerk packages:** `cd backend && npm install @clerk/backend` and `npm install @clerk/nextjs` (frontend)
3. **Generate Drizzle migrations:** `cd backend && npm run db:generate`
4. **Run PostgreSQL:** `docker compose up -d database`
5. **Run migrations:** `cd backend && npm run db:migrate`
6. **Seed data:** `cd backend && npm run db:seed`
7. **Start backend:** `cd backend && npm run start:dev`
8. **Start full stack:** `docker compose up`

### Next Steps Priority Order:
1. **Phase 5** (Clerk Auth) — Foundation for everything; replaces Firebase entirely
2. **Phase 6** (DB Migration + Patient API validation) — Migration schemas, then wire org scoping
3. **Phase 7** (Frontend Clerk Integration) — Can proceed in parallel once backend auth works
4. **Phase 8** (Testing) — Needed before any merge
5. **Phase 8** (Mastra) — Deferred AI workflows; scaffolding only
