## How to Continue

1. **Install backend dependencies:** `cd backend && npm install`
2. **Generate Drizzle migrations:** `cd backend && npm run db:generate`
3. **Run PostgreSQL:** `docker compose up -d database`
4. **Run migrations:** `cd backend && npm run db:migrate`
5. **Seed data:** `cd backend && npm run db:seed`
6. **Start backend:** `cd backend && npm run start:dev`
7. **Start full stack:** `docker compose up`
